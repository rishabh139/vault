### **I. LFP Spectral & Aperiodic Features (The "State")**
*These features describe the tonic, background state of the hippocampal network. They are computationally cheap and highly informative.*

| Feature Name                        | Supporting Paper(s)                                                            | What It Means (Biological Rationale)                                                                                                                                                                                             | How to Compute on HD-MEA Data                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| :---------------------------------- | :----------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. LFP Power in Canonical Bands** | **Marques et al. (2022)**, **Tomar et al. (2020)**, **Pelkonen et al. (2024)** | The power in a frequency band reflects the strength and synchrony of synaptic inputs driving that rhythm. Different bands are linked to different functions (Theta: memory/control, Gamma: local computation, Delta: pathology). | 1. For each electrode, calculate the Power Spectral Density (PSD) using Welch's method (`scipy.signal.welch`). <br>2. Integrate the power within each band of interest: Delta (1-4 Hz), Theta (4-12 Hz), Alpha (8-13 Hz), Beta (14-30 Hz), Slow Gamma (30-55 Hz), Fast Gamma (65-100 Hz). <br>3. Normalize the power in each band (e.g., as a percentage of total power from 1-100 Hz) to compare across slices. <br>4. Average the normalized power values for each band across all active electrodes to get a single feature value per slice. |
| **2. Aperiodic Exponent**           | **Bergosh et al. (2023)**                                                      | A proxy for the Excitation/Inhibition (E/I) balance in the underlying circuit. A steeper slope (larger exponent) suggests more inhibition, while a flatter slope (smaller exponent) suggests more excitation.                    | 1. Calculate the PSD for each electrode (as above). <br>2. Use the Python `specparam` (FOOOF) library to fit the power spectrum. <br>3. The model directly outputs the aperiodic exponent as a feature. <br>4. Average this exponent value across all active electrodes.                                                                                                                                                                                                                                                                        |
| **3. Aperiodic Offset**             | **Bergosh et al. (2023)**                                                      | The broadband power offset of the LFP spectrum, reflecting the total baseline neural activity independent of oscillations. Can be a general measure of network activity or "noisiness."                                          | 1. Use the same `specparam` (FOOOF) model from the step above. <br>2. The model directly outputs the aperiodic offset as a feature. <br>3. Average this offset value across all active electrodes.                                                                                                                                                                                                                                                                                                                                              |

### **II. LFP Event-Based Features (The "Dynamics")**
*These features characterize the properties of spontaneous, synchronous network events, which are a hallmark of slice activity.*

| Feature Name                        | Supporting Paper(s)                               | What It Means (Biological Rationale)                                                                                                                                                              | How to Compute on HD-MEA Data                                                                                                                                                                                                                                                                                                                                                                                                                               |
| :---------------------------------- | :------------------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **4. Sharp-Wave Ripple (SWR) Rate** | **Kuga et al. (2023)**, **Tomar et al. (2019)**   | SWRs are brief, high-frequency oscillations crucial for memory consolidation. An abnormally high rate is linked to the pathological consolidation of aversive memories and stress susceptibility. | 1. Band-pass filter the LFP from each electrode in the ripple band (e.g., 150-250 Hz). <br>2. Calculate the instantaneous power envelope (e.g., using the Hilbert transform). <br>3. Detect events where power exceeds a threshold (e.g., >3-5 SD above the mean) for a minimum duration (e.g., >15-30 ms). <br>4. Count the total number of valid SWR events across the array. <br>5. Divide by the total recording duration (in minutes) to get the rate. |
| **5. SWR Duration & Amplitude**     | **Tomar et al. (2019)**                           | The intrinsic morphological properties of SWR events. Stress has been shown to make them longer and larger in amplitude, suggesting a change in the underlying synchronous neuronal activity.     | 1. Use the detected SWR events from the step above. <br>2. For each event, calculate its duration (time from crossing the threshold to falling back below it). <br>3. For each event, find the peak amplitude of the filtered ripple-band signal. <br>4. Average the duration and amplitude across all events in the recording.                                                                                                                             |
| **6. LFP Event "Size"**             | **Kim et al. (2023)**, **Pelkonen et al. (2024)** | A simple proxy for network synchrony. It measures the spatial extent of a network burst, quantifying how many local populations are co-active during a synchronous event.                         | 1. Define a network event (e.g., using the SWR detection method or a lower-frequency burst detector). <br>2. For each event, count the number of electrodes that show significant activity within that time window. <br>3. Express this count as a percentage of the total number of active electrodes on the array. <br>4. Average this percentage across all events.                                                                                      |

### **III. Spike Train & Multi-Unit Activity (MUA) Features (The "Output")**
*These features are derived from spiking data. To avoid issues with single-unit sorting, they can be computed on the multi-unit activity (MUA) from each electrode.*

| Feature Name                          | Supporting Paper(s)                             | What It Means (Biological Rationale)                                                                                                                                                                          | How to Compute on HD-MEA Data                                                                                                                                                                                                                                                                                                 |
| :------------------------------------ | :---------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **7. Mean Firing Rate (MFR)**         | **Park et al. (2015)**, **Trem2 et al. (2024)** | The most fundamental measure of neuronal excitability. Can indicate a state of hypo- or hyperactivity. Note: literature is mixed, with some stress models showing increases and others decreases.             | 1. For each electrode, detect spike times from the band-passed filtered signal (e.g., 300-3000 Hz) using a threshold (e.g., -5.5 SD of noise). <br>2. Count the total number of spikes. <br>3. Divide by the recording duration to get the rate in Hz. <br>4. Average this rate across all active electrodes.                 |
| **8. MUA Burst Rate**                 | **Park et al. (2015)**, **Kim et al. (2023)**   | The frequency of high-frequency firing events. Reflects the network's tendency to engage in a bursting mode of information transfer, which is critical for synaptic plasticity.                               | 1. For each electrode's spike train, use a burst detection algorithm (e.g., define a burst as ≥2 spikes with an inter-spike interval <15 ms, as per **Park et al.**). <br>2. Count the number of detected bursts. <br>3. Divide by the recording duration to get the burst rate. <br>4. Average across all active electrodes. |
| **9. Intra-Burst Interval (IntraBI)** | **Park et al. (2015)**                          | The average time between spikes *within* a burst. A direct measure of the temporal precision of burst firing. Longer IntraBIs suggest a "slower," more disorganized burst structure linked to chronic stress. | 1. Using the bursts detected above, calculate the inter-spike interval (ISI) for all consecutive spikes within each burst. <br>2. Average these ISIs to get the mean IntraBI for each burst. <br>3. Average the IntraBI across all bursts on an electrode, and then across all active electrodes.                             |

### **IV. Network & Coordination Features (The "Interactions")**
*These features measure how different components of the network interact. They are chosen to be computationally tractable.*

| Feature Name                                        | Supporting Paper(s)                                   | What It Means (Biological Rationale)                                                                                                                                                                                       | How to Compute on HD-MEA Data                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| :-------------------------------------------------- | :---------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **10. Theta-Gamma Phase-Amplitude Coupling (PAC)**  | **Goutagny et al. (2013)**, **Marques et al. (2022)** | A measure of hierarchical control, where the phase of the slow theta rhythm modulates the power of fast gamma oscillations. Strong PAC is a signature of a healthy, coordinated network and has been linked to resilience. | 1. For each electrode's LFP: <br> a. Extract the theta phase (filter 4-12 Hz, then Hilbert transform). <br> b. Extract the gamma power envelope (filter 30-100 Hz, Hilbert transform, take absolute value). <br> 2. Calculate a Modulation Index (MI) that quantifies how non-uniform the distribution of gamma power is across theta phases (using the method of **Tort et al., 2010**). <br> 3. Perform a surrogate analysis (shuffling) to get a z-scored MI. <br> 4. Average the z-scored MI across all active electrodes. |
| **11. Mean Pairwise Correlation (Subsampled)**      | **Trem2 et al. (2024)**                               | A computationally cheap proxy for global network synchrony. Measures the average tendency of neuron pairs to fire together in time.                                                                                        | 1. Randomly select a subset of N active electrodes (e.g., N=200). <br> 2. For each electrode, bin its spike train into a time vector (e.g., 10 ms bins). <br> 3. Calculate the zero-lag Pearson correlation between the binned spike vectors for every pair of electrodes in the subset. <br> 4. Apply a Fisher's r-to-z transform to the correlation values. <br> 5. Average the z-scored values to get a single feature for the slice.                                                                                       |
| **12. Global Efficiency (from a subsampled graph)** | **Tanglay et al. (2023)**, **Kim et al. (2023)**      | A graph theory metric that measures the overall efficiency of information transfer in the network. Resilient networks are hypothesized to be more efficient.                                                               | 1. Use the correlation values from the subsampled network above to create a weighted adjacency matrix. <br> 2. You may need to threshold this matrix to create a binary graph (e.g., keep the top 10% of connections). <br> 3. Use a library like `NetworkX` in Python to calculate the global efficiency of this graph. This gives you one value per slice.                                                                                                                                                                   |

### **V. Advanced Complexity & State-Space Features (The "Fingerprint")**
*These are more abstract features that describe the complexity and structure of the network's activity patterns. They represent a Tier 2 or 3 analysis.*

| Feature Name                                             | Supporting Paper(s)       | What It Means (Biological Rationale)                                                                                                                                                                                                                            | How to Compute on HD-MEA Data                                                                                                                                                                                                                                                                                                                                                   |
| :------------------------------------------------------- | :------------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **13. LFP Sample Entropy**                               | **Bergosh et al. (2023)** | A measure of the irregularity and unpredictability of the LFP signal. Higher entropy can indicate more chaotic or complex dynamics, while lower entropy suggests more regular, predictable (oscillatory) activity. It was a powerful biomarker of stress state. | 1. For each electrode's LFP time-series, use a library (e.g., `EntroPy` in Python) to calculate the sample entropy. Key parameters are the embedding dimension (`m`) and tolerance (`r`). <br> 2. Average the sample entropy value across all active electrodes.                                                                                                                |
| **14. State-Space Dimensionality (Participation Ratio)** | **Xia et al. (2023)**     | Measures the complexity of population activity patterns. Higher dimensionality suggests the network explores a greater number of distinct activity patterns or "neural states," which was linked to susceptibility.                                             | 1. Select a subset of N active electrodes (e.g., N=100-200). <br> 2. Create a population activity matrix by binning the spike trains of these electrodes. <br> 3. Perform Principal Component Analysis (PCA) on this matrix to get the eigenvalues. <br> 4. Calculate the Participation Ratio from the eigenvalues. This gives a single dimensionality value for the recording. |
